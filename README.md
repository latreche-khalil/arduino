# منصة ورشات الأستاذ خليل للأردوينو والابتكار للأطفال 🏫⚡

منظومة تعليمية تفاعلية متكاملة لإدارة وتقديم ورشات أسبوعية تطبيقية في الإلكترونيات، برمجة المتحكمات الدقيقة (Arduino)، والابتكار الهندسي للأطفال والناشئين.

---

## 🔐 نظام بوابة دخول وقبول التلاميذ (Classroom Gate)

تم تزويد المنصة بنظام تحكم ذكي وفوري لإدارة حضور التلاميذ وقبولهم:

1. **بوابة التلميذ (Student Gate):**
   - عند فتح المنصة يظهر قفل ترحيبي يطلب من التلميذ إدخال اسمه وفside/فوزه.
   - يتحول التلميذ إلى **غرفة انتظار حية** تبث طلبه للأستاذ مباشرة عبر خادم WebSockets/MQTT السحابي والبث المحلي.
   - فور موافقة الأستاذ، تصدر المنصة نغمة ترحيبية احتفالية وتفتح له كامل المحتوى مع شارة اتصال باسمه.

2. **لوحة تحكم الأستاذ خليل (`admin.html`):**
   - محمية برمز مرور سري خاص بالأستاذ (الرمز الافتراضي: `142005`).
   - استعراض طلبات التلاميذ المعلقة بالوقت والاسم لحظياً.
   - إمكانية **«قبول الكل بنقرة واحدة»** أو قبول فردي ورفض.
   - تفعيل خيار **«القبول التلقائي (Auto-Admit)»** أثناء الشرح والدروس.
   - إمكانية عرض **«رمز الحصة السريع (2026)»** على شاشة العرض أو السبورة.
   - تصدير كشف الحضور بنقرة زر أو نسخه إلى الحافظة.

## 🌟 المشاريع الأسبوعية المتاحة

### 1. ⚡ الأسبوع الأول: لعبة سلك الإنذار والتركيز (Buzzer Wire Game)
- **فكرة المشروع:** لعبة تحدي ثبات اليد والتركيز الكلاسيكية؛ سلك نحاسي متعرج وحلقة يمررها المتسابق دون ملامسة السلك.
- **المفاهيم العلمية:** الدوائر الكهربائية المغلقة والمفتوحة، المقاومة الداخلية `INPUT_PULLUP`، والتحكم بالنغمات عبر دالة `tone()`.
- **المكونات:** لوحة Arduino Uno، طنان صوتي (Buzzer)، مصابيح LED، سلك متعرج وحلقة نحاسية.
- **المسار:** `projects/buzzer-wire-game/`

### 2. 🏠 الأسبوع الثاني: المنزل الذكي والباب الأوتوماتيكي بـ RFID (Smart RFID Door)
- **فكرة المشروع:** باب منزل أوتوماتيكي ذكي يفتح بمحرك سيرفو فور تمرير بطاقة RFID المصرح بها، ويطلق إنذاراً صوتياً تنبيهياً عند تمرير بطاقة مجهولة.
- **المفاهيم العلمية:** بروتوكول الاتصال SPI، قراءة الأكواد الفريدة للبطاقات (UID)، اتخاذ القرارات الشرطية (`if/else`)، والتحكم بزوايا محركات السيرفو (SG90).
- **المكونات:** لوحة Arduino Uno، قارئ RFID-RC522، محرك سيرفو SG90، طنان صوتي Buzzer، مجسم باب ومنزل كرتوني.
- **المسار:** `projects/rfid-smart-door/`

## 🚀 كيفية التشغيل محلياً

1. استنسخ المستودع:
   ```bash
   git clone https://github.com/latreche-khalil/arduino.git
   ```
2. افتح مجلد المشروع:
   ```bash
   cd arduino
   ```
3. شغّل خادم محلي:
   ```bash
   python -m http.server 5500
   ```
4. افتح المتصفح على:
   - بوابة الطلاب: `http://localhost:5500/index.html`
   - لوحة تحكم الأستاذ: `http://localhost:5500/admin.html` (الرمز: `142005`)
