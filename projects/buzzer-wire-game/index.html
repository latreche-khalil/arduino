المكونات الإلكترونية للعبة

القطع التي استخدمها الطلاب في ورشة العمل لصنع دارة سلك الإنذار:

العقل 🧠

Arduino Uno

المتحكم الدقيق
دوره: قراءة إشارة الحلقة المعدنية على المنفذ D2 والتحكم الفوري في تشغيل مصباح التنبيه وجرس الإنذار عند التلامس.
الصوت 🔊

جرس الإنذار (Buzzer)

الإنذار الصوتي
دوره: متصل بالمنفذ D8؛ يطلق نغمة بتردد 1000Hz بمجرد ملامسة الحلقة للمسار النحاسي.
الضوء 💡

مصباح LED ومقاومة 220Ω

مؤشر بصري
دوره: متصل بالمنفذ D7؛ يضيء باللون الأحمر فور وقوع خطأ التلامس لحماية العين وتنبيه اللاعب.
المسار ➰

سلك المسار النحاسي والحلقة

Copper Track & Ring
دوره: المسار موصول بـ GND، والحلقة موصولة بالمنفذ D2؛ وعند التلامس تكتمل الدارة الكهربائية.
🔌 طريقة التوصيل المعتمدة

مخطط وجدول توصيل الدارة الكهربائية

توصيل مباشر وبسيط يعتمد على غلق الدارة وتوصيل المنفذ بالأرضي GND عند التلامس:

جدول توصيلات لعبة سلك الإنذار

المكون منفذ Arduino طريقة التوصيل
المسار النحاسي المتعرج GND سكة الأرضي في لوح التجارب Breadboard
الحلقة المعدنية (المقبض) D2 سلك مرن معزول مع خاصية INPUT_PULLUP
مصباح LED (الطرف الطويل +) D7 عبر مقاومة حماية 220Ω
مصباح LED (الطرف القصير -) GND سكة الأرضي المشتركة
جرس الإنذار Buzzer (+) D8 المنفذ الرقمي للتحكم بالتردد tone()
جرس الإنذار Buzzer (-) GND سكة الأرضي المشتركة

🧠 كيف تعمل فكرة التلامس (INPUT_PULLUP)؟

عند تفعيل INPUT_PULLUP للمنفذ D2، يرفع الأردوينو الجهد داخلياً إلى 5V وتكون الحالة HIGH ما دامت الحلقة في الهواء بعيدة عن المسار.

بمجرد أن تلمس الحلقة المسار النحاسي الموصول بـ GND، يكتمل الاتصال بالأرضي فوراً وتهبط القيمة إلى LOW، فيطلق الأردوينو الإنذار الصوتي والضوئي بالملي ثانية!

⚠️ تنبيهات هامة للسلامة:
  • لا توصل المسار النحاسي أبداً بجهد 5V تجنباً لقصر الدارة الكهربائية.
  • افصل كابل USB دائماً قبل تغيير أي سلك على لوح التجارب.

برنامج لعبة سلك الإنذار الكامل

كود الدرس كما شرحه الأستاذ خليل، منظم وسهل القراءة مع تعليقات عربية:

📄 BuzzWireGame.ino 
// Arduino Quest - Buzz Wire Challenge

// تحديد منافذ المكونات
const int sensorPin  = 2;
const int ledPin     = 7;
const int buzzerPin  = 8;

void setup() {
  // إعداد المنافذ
  pinMode(sensorPin, INPUT_PULLUP);
  pinMode(ledPin,    OUTPUT);
  pinMode(buzzerPin, OUTPUT);
}

void loop() {
  // قراءة حالة الحلقة المعدنية
  int state = digitalRead(sensorPin);

  // التحقق من حدوث التلامس
  if (state == LOW) {
    // الحلقة تلامس المسار النحاسي
    digitalWrite(ledPin, HIGH);
    tone(buzzerPin, 1000);
  } else {
    // الحلقة لا تلامس المسار النحاسي
    digitalWrite(ledPin, LOW);
    noTone(buzzerPin);
  }
}


/*
طريقة تركيب الدارة:
1. GND → المسار النحاسي وسكة الأرضي في Breadboard.
2. D2  → الحلقة المعدنية بسلك مرن معزول.
3. D7  → مقاومة 220Ω → الطرف الطويل لـ LED.
         الطرف القصير لـ LED → GND.
4. D8  → الطرف الموجب (+) للجرس السلبي.
         الطرف السالب (-) للجرس → GND.

تنبيه: لا توصل المسار النحاسي بـ 5V،
وافصل USB قبل تغيير التوصيلات.
*/
