# 📖 دليل الأستاذ خليل: كيف تضيف مشروعاً جديداً كل أسبوع؟

أهلاً بك يا أستاذ خليل! لقد صُمم هذا النظام التعليمي ليكون **معياريًا ومرنًا للغاية**، بحيث يمكنك إضافة درس جديد كل أسبوع في 3 خطوات بسيطة:

---

## 🚀 الخطوات الثلاث لإضافة درس جديد:

### الخطوة 1: انسخ مجلد القالب
1. انسخ مجلد `projects/lesson-template`
2. غيّر اسمه لاسم مشروعك الجديد بالإنجليزية (مثال: `projects/traffic-light` أو `projects/robot-car`).

### الخطوة 2: املأ محتوى درسك في صفحة `index.html`
افتح ملف `index.html` داخل المجلد الجديد وستجد أماكن محددة وواضحة لكل قسم:
- عنوان المشروع والوصف
- صور المكونات
- جدول ومخطط التوصيلات
- كود أردوينو الكامل المعتمد
- خطوات البناء اليدوي
- جدول الاختبار السريع
- تحديات الطلاب ومسابقة الأسئلة

### الخطوة 3: أضف المشروع في السجل المركزي `data/projects.json`
افتح الملف `data/projects.json` وأضف كائن المشروع الجديد:
```json
{
  "id": "traffic-light",
  "week": 2,
  "title": "نظام إشارات المرور الذكية",
  "titleEn": "Smart Traffic Light",
  "summary": "وصف موجز للمشروع في سطرين...",
  "status": "active",
  "statusLabel": "متاح الآن للطلاب 🟢",
  "duration": "50 دقيقة",
  "level": "مبتدئ ⭐⭐",
  "category": "أنظمة المدن الذكية",
  "image": "assets/images/traffic_light.jpg",
  "url": "projects/traffic-light/index.html",
  "components": ["Arduino Uno", "LEDs", "Button", "Resistors"],
  "learningGoals": [
    "الهدف الأول...",
    "الهدف الثاني..."
  ]
}
```

---

## 🎉 النتيجة:
بمجرد حفظ الملف:
1. ستظهر البطاقة الخاصة بالأسبوع الجديد فوراً في الصفحة الرئيسية للبوابة (`index.html`).
2. ستظهر الحصة في القائمة المنسدلة في شريط التنقل العلوي لجميع الدروس.
3. يستطيع الطلاب وأولياء الأمور تصفح الأرشيف والمشاريع السابقة والقادمة بكل سهولة واحترافية!
